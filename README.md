# Расписание занятий и задания

Статический сайт на HTML, CSS и JavaScript: откройте `index.html` локально. Для получения заданий из GitHub Pages сайт загружает `tasks.json`.

## Telegram-бот (Python)

Бот записывает задания в `tasks.json` репозитория `SsixM/automeh108`. Список предметов и дни уроков собраны в одной константе `LESSONS` в `bot.py`. Сообщение вида `Математика выучить степени 9.11` означает: задано 9 ноября, показать под ближайшей математикой после этой даты.

1. Создайте Telegram-бота через BotFather.
2. Создайте GitHub fine-grained token только для `SsixM/automeh108`, разрешение **Contents: Read and write**. Не добавляйте токен в файлы репозитория.
3. Установите Python и зависимость: `python -m pip install python-telegram-bot`.
4. Задайте переменные окружения `TELEGRAM_BOT_TOKEN` и `GITHUB_TOKEN`, затем запустите `python bot.py`.
5. В приватном репозитории включите GitHub Pages. Для публичного репозитория помните: опубликованный `tasks.json` доступен посетителям сайта.

Не коммитьте токены. Бот использует GitHub Contents API и работает на компьютере/сервере, где запущен Python; один только GitHub Pages не может безопасно хранить секреты и принимать Telegram updates. Ограничьте доступ к боту списком разрешённых Telegram user ID перед использованием, если бот будет доступен другим людям.
