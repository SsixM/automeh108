# 108М — учебный дневник

Статический сайт и Telegram-бот для группы **108М**: расписание, оценки, домашние задания,
дежурства и замены. Сайт читает только JSON из `data/`, бот — единственный компонент,
который пишет данные в GitHub.

- Сайт: GitHub Pages, mobile-first, без авторизации.
- Бот: Python 3.11+, один файл `bot.py`, Telegram + Gemini + GitHub Contents API.
- Секреты: только переменные окружения, никогда не файлы репозитория.

## Быстрый старт

```bash
python -m pip install -r requirements.txt
cp .env.example .env          # заполните значения
python bot.py
```

Без обязательных переменных бот завершится с понятной ошибкой, а не traceback.

### Обязательные переменные

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота от BotFather |
| `ALLOWED_TELEGRAM_IDS` | Числовые Telegram ID через запятую |
| `GITHUB_TOKEN` | Fine-grained token с **Contents: Read and write** |
| `GEMINI_API_KEY` | Ключ Gemini API |

### Необязательные переменные

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `GITHUB_REPOSITORY` | `SsixM/automeh108` | Репозиторий с `data/` |
| `GITHUB_BRANCH` | `main` | Ветка публикации |
| `DATA_DIR` | `data` | Каталог JSON внутри репозитория |
| `GEMINI_MODELS` | встроенный список | Модели через запятую, первая — основная |
| `GEMINI_RPM_LIMIT` | `5` | Локальный лимит запросов в минуту |
| `GEMINI_RPD_LIMIT` | `20` | Локальный лимит запросов в день |
| `GEMINI_TPM_LIMIT` | `250000` | Локальный лимит токенов в минуту |
| `VK_GROUP_ID` | — | Числовой id сообщества без минуса |
| `VK_ACCESS_TOKEN` | — | Сервисный токен VK для чтения стены |
| `BOT_STATE_FILE` | `bot_state.local.json` | Локальные отметки, не публикуется |
| `LOG_LEVEL` | `INFO` | Уровень логов |

`VK_GROUP_ID` и `VK_ACCESS_TOKEN` нужны только для автоматического импорта замен в 20:00.
Без них бот работает, а PDF замен можно переслать вручную.

## Что умеет бот

### Домашнее задание

```text
Математика выучить логарифмы 10.09
```

- Дата в конце: `ДД.ММ`, `ДД.ММ.ГГ`, `ДД.ММ.ГГГГ`; без даты — дата сообщения.
- Задание привязывается к следующему действующему уроку предмета с учётом чётности недели и замен.
- Второе сообщение по тому же предмету добавляет **ещё одно** задание; на сайте оно показывается ниже.
- Одинаковый текст дважды не дублируется.

### Фото к домашнему заданию

Отправьте фото с подписью:

```text
ДЗ Математика выучить логарифмы
```

До 6 изображений к одному заданию. Фото без подписи считаются фотографиями журнала.
Вложения публикуются в `media/homework/` и доступны на сайте; журнальные фотографии
в GitHub не публикуются.

### Дежурства

```text
Дежурили Абакаев, Бадреев, Осадчий
```

- Принимаются фамилия, имя, ФИО и небольшие опечатки.
- Два отчёта за день объединяются: засчитаны будут все, кого называли.
- Без отчёта день закрывается без начисления.
- Пожелания по парам: `/pair Абакаев Бадреев`, удалить — `/unpair Абакаев Бадреев`,
  показать — `/pairs`. Бот учитывает пару, если оба ученика в минимальном слое дежурств.

### Журнал

Фото или альбом **без подписи**. Бот ждёт завершения альбома, сжимает изображение,
учитывает EXIF-поворот и не отправляет повторное фото в Gemini по SHA-256.
PDF как журнал не принимается.

### Замены

- Перешлите PDF замен документом: бот разберёт только строки `108М`.
- В 20:00 бот пытается найти пост с PDF в VK; без VK-токенов присылает инструкцию.
- PDF должен содержать текстовый слой и дату вида `Замены на 21.11.2026`.
- Сканы без текстового слоя не распознаются: нужен текстовый PDF или ручной ввод.

### Команды

| Команда | Действие |
| --- | --- |
| `/start`, `/help` | Инструкция |
| `/today` | Расписание, замены и ДЗ на сегодня |
| `/grades` | Сводка по оценкам и спорным записям |
| `/duties` | Последние дежурства |
| `/pair`, `/unpair`, `/pairs` | Пожелания по парам дежурных |
| `/review` | Подтверждение спорных оценок |
| `/status` | Очередь, revision, квоты Gemini |
| `/cancel` | Отменить незавершённую загрузку фото |

## Данные и публикация

`data/manifest.json` и семь файлов данных публикуются с одной `revision`.
`manifest.json` записывается последним. При конфликте GitHub (`409`/`422`) бот
перечитывает файлы, заново применяет идемпотентные изменения и повторяет запись
до 5 раз.

Файлы:

```text
data/students.json      33 ученика, стабильные s01…s33
data/schedule.json      уроки, звонки, правила замен
data/grades.json        оценки и посещаемость
data/tasks.json         домашние задания и вложения
data/duties.json        дежурства и пожелания по парам
data/replacements.json  замены только для 108М
data/reviews.json       спорные оценки
data/manifest.json      revision и список файлов
```

Схемы: `schemas/*.schema.json`. Тесты проверяют схемы, 33 ученика, единую revision,
фильтр замен, слияние оценок, CAS и идемпотентность.

## GitHub Pages

1. Запушьте ветку с сайтом в GitHub.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, каталог `/ (root)`.
3. Сайт будет доступен по адресу вида `https://<user>.github.io/automeh108/`.

**Важно:** GitHub Pages публичен. Любой, кто знает ссылку, увидит ФИО, оценки и ДЗ.
Авторизации на статическом сайте нет.

## Запуск на Aurorix

Бот — обычный долгоживущий процесс, входящий порт ему не нужен.

1. Установите Python 3.11+ и зависимости: `python -m pip install -r requirements.txt`.
2. Задайте переменные окружения в панели Aurorix (не в файле репозитория).
3. Команда запуска: `python bot.py`.
4. Включите автоперезапуск при падении.
5. Сохраняйте `bot_state.local.json` между перезапусками (постоянный диск), иначе
   бот может повторно обработать старые Telegram updates.
6. Токену GitHub нужны права **Contents: Read and write** на репозиторий с `data/`.

Для проверки конфигурации без Telegram можно запустить `python bot.py` без переменных:
он завершится с сообщением, каких переменных не хватает.

## Тесты

```bash
python -m pytest -q
npm test
```

Node-тесты проверяют чистые функции фронтенда (`escapeHtml`, чётность недели,
замены, дедлайны, дежурства). Python-тесты — схемы, CAS, парсеры, дежурства,
Gemini-слияние и замены.

## Безопасность

- Секреты читаются только из окружения. В репозитории нет `.env`.
- `.gitignore` исключает `.env`, `bot_state.local.json`, `__pycache__`, фото, PDF и логи.
- Allowlist проверяется до скачивания файлов и вызова внешних API.
- Логи не содержат токенов, полных ответов API и персональных данных.
- Повторный Telegram update блокируется по `update_id`; данные идемпотентны по
  естественным ключам.
- Старые токены, которые уже попадали в переписку или черновики, нужно отозвать
  и перевыпустить. Бот их не использует.

## Известные ограничения

1. **Публичный сайт.** GitHub Pages не даёт авторизации; ФИО и оценки видны по ссылке.
2. **PDF только с текстовым слоем.** OCR сканированных PDF не реализован.
   Скан нужно заменить текстовым PDF или ввести замены вручную.
3. **VK API.** Автопоиск работает только для открытой стены и сервисного токена;
   при ошибке бот просит переслать PDF вручную.
4. **Gemini-квоты.** Лимиты локальные; при исчерпании обработка останавливается
   без потери уже сохранённых оценок.
5. **Медиа ДЗ публичны.** Вложения домашних заданий публикуются в `media/homework/`,
   потому что статическому сайту нужен прямой URL. Журнальные фото не публикуются.
6. **Расписание.** Специальные правила чётности и замен вынесены в `schedule.json`;
   при изменении сетки их нужно править данными, а не кодом.
7. **Один экземпляр бота.** Одновременный запуск двух процессов с одним
   `bot_state.local.json` не поддерживается.
